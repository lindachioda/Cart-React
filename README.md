# 🛒 Shopping Cart – React & TypeScript

An interactive shopping cart application developed as part of a guided React exercise.
The guided project focuses on managing application state with **useReducer** and **useContext**, allowing users to interact with products and dynamically update their shopping cart.

## ✨ Features

- Fetch product data from a custom JSON Server API.
- Increase product quantities.
- Decrease product quantities.
- Remove individual products from the cart.
- Empty the entire cart.
- Automatically calculate and update the total price.
- Handle loading and error states while fetching data.

## 🎯 Learning Goals

- Understanding state management with `useReducer`.
- Sharing global state using `useContext`.
- Working with TypeScript types and interfaces.
- Fetching API data with Axios.
- Managing product quantities and calculating totals.
- Handling asynchronous operations and API errors.
